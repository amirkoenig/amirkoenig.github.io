# amirkoenig.github.io

Personal site of Amir König, served by GitHub Pages from the `main` branch.

Plain static files, no build step:

- `index.html`: the whole page, including the SVG illustrations
- `assets/site.css`, `assets/site.js`: styles and behaviour (canvas sky, scroll reveals, index deck)
- `404.html`: not-found page

Preview locally with `python3 -m http.server` in this folder.
